{#- Fragment: the toggle form of a card (source or profile), the markup shared by sources/_toggle_form.html and profiles/_toggle_form.html. An include shares the including template's context, so the host provides the four fields as flat context fields: `toggle_url` (the POST endpoint of the card), `enabled` (the state the form flips), `csrf` and `swap_oob`. The POST form carries the CSRF token in the hidden `_csrf` field, taken from the `csrf` field of the template context. The button carries the action, not the state ("Disable" on an enabled card), and the state lives in the badge next to it, so the button has no aria-pressed. The button is disabled while the request runs, so a second click cannot flip the flag twice, and the response error is printed into the slot the page keeps next to the badge. -#}
