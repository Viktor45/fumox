{#- Fragment: the toggle form of the profile card, included by the detail page for the initial render and re-rendered by the toggle action. In the swap response `swap_oob` adds the hx-swap-oob attribute so the form replaces itself out-of-band; the page renders it plain. The button carries the action, not the state ("Disable" on an enabled profile), and the state lives in the badge next to it, so the button has no aria-pressed. The button is disabled while the request runs, so a second click cannot flip the flag twice, and the response error is printed into the slot the page keeps next to the badge. -#}
